# GeoMine Resource Hub Screenshots

Place your three authentic GeoMine application screenshots in this directory:

1. `course-list.png` — Screenshot of the 8-semester curriculum navigation and course catalog.
2. `pdf-viewer.png` — Screenshot of the in-browser PDF document viewer interface.
3. `upload-flow.png` — Screenshot of the Course Representative upload form and validation flow.

Recommended resolution: 1600x1000 or 1920x1200 (aspect ratio ~16:10), PNG or JPG format.
When added, `GeoMineGallery` will automatically display them with smooth zoom and clean border framing.
